Aportes de la comunidad

Buzón de Aportes

Comparte apuntes, certámenes, controles, guías o material útil para estudiantes de Telemática. En la versión Django local el flujo usa correo USM, PIN y subida segura.

Versión estática de GitHub Pages

GitHub Pages muestra la interfaz, pero no ejecuta backend. Para usar el envío real de archivos, ejecuta la app Django local o despliega el contenedor con `docker compose up -d --build`.

1. Correo USM

Validación institucional.

2. PIN

Confirmación segura.

3. Archivo

Subida y revisión.
